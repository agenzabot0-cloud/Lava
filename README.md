# Lava
Lava Is a fast and powerful coding language written purely in JavaScript.
## Example snippets
you can use this snippet when coding
```Lava
  print hello world!
  ```
 which then prints an output like `hello world!`
 ## Adding variables
 first off when adding variables, use `set MyVar 10` to declare the variable, then use `flow` to add it, look:
 ```Lava
    set MyVar 10
    flow MyVar 1
```
